Our team will work collaboratively to deliver one functional application.

## 🔐 SECURITY PRINCIPLES

The team agrees to:

1. Avoid exposing passwords, API keys or secret credentials.
2. Use synthetic learner information for demonstrations.
3. Protect learner records from unauthorized access.
4. Validate progress data before storing it.
5. Enable Supabase Row Level Security where applicable.
6. Avoid unnecessary personal information collection.
7. Test offline data persistence and synchronization.
8. Consult Aashma on security-related implementation decisions.
