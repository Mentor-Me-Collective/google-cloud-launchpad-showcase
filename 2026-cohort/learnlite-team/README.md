
# LearnLite — Offline-First AI Learning Platform

**MMC x Google Cloud Launchpad | 2026 Cohort**

## Project Overview

LearnLite is an offline-first, AI-assisted learning
platform designed to help teachers create learning
modules, manage classrooms and support students
in environments with limited internet connectivity.

The application is being developed for Android,
iOS and Web.

## Technology Stack

- Google Cloud Run — Python FastAPI backend
- Firebase Authentication — User authentication
- Cloud Firestore — Application database
- Google Cloud Storage — Learning materials
- Expo / React Native — Mobile and web application
- NVIDIA — Planned AI integration
- GitHub — Version control and collaboration
