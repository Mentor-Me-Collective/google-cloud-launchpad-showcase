# Contributing and review procedure

- Create issues tagged `product`, `data`, `ai`, `cloud`, `security`, `docs`, `submission`.
- PRs describe requirement ID, ADR, test evidence, screenshots (without secrets), risks and rollback.
- Product workflow PRs: Justin review; pipeline: Blanca; data: Kseniya; security: Shiksha; AI: named owner TBD.
- Block merge for failing authorization/security tests or source-provenance violations.
- Do not commit API keys or real personal data. All synthetic content is clearly marked DEMO.
- Version or supersede decisions; avoid editing history silently.
