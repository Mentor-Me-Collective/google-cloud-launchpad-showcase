# ADR-002: Limit MVP to extreme heat and two demo tenants

- **Status:** Proposed
- **Owner:** Justin
- **Date:** 2026-10-27

## Context

Four-week build with limited team cannot safely cover many climate hazards.

## Decision

Extreme-heat alerts/forecasts only; 5–10 sourced public sample facilities in Mott Haven/Melrose; two fictional DEMO organizations. Include specified workflow and history; defer flood, wildfire, IoT, emergency dispatch.

## Consequences

Focused data testing and demonstrable value; general hazard coverage postponed.

## Verification / revisit condition

Link acceptance test(s), recorded reviewer approval, implementation PR and evidence of behavior before changing status to Accepted. Revisit if field user feedback, API behavior or security tests contradict assumptions.
